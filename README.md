# The World in One Page — Sunday, November 22, 2026

A one-image summary of the world's news of **Sunday, 22 November 2026**,
drawn as a newspaper front page: COP31 nears a deal in Antalya with
fossil fuels still missing from the text, NATO vows to defend every
inch of Poland, a supercell storm levels a Brazilian town, a funeral
boat capsizes in Nigeria, Mexico captures an FBI most-wanted cartel
boss, and hackers breach the FBI database and U.S. farm payments.

This repository is an entry in the make.fun competition
[Sum up 22 November's world news in one image](https://make.fun/c/news-image-20261122).

## How it runs

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to `/output/entry.png`. It runs twice in the grader's
sandbox and writes identical bytes both times. Locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
